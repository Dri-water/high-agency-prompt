# High Agency Prompt

One short prompt that makes AI agents act with initiative instead of waiting for instructions.

No framework, no skill tree, no setup. Just the prompt: [`prompt.md`](prompt.md).

## Use it

Paste it into your agent's system prompt or custom instructions, e.g.:

- **Claude Code**: `CLAUDE.md`
- **Codex / other agents**: `AGENTS.md`
- **ChatGPT / Claude apps**: custom instructions

Or fetch it:

```bash
curl -O https://raw.githubusercontent.com/Dri-water/high-agency-prompt/main/prompt.md
```
